# Mobile-wallet-fraud-detection-NextGen-AI-internship-final-project
Mobile-Wallet Fraud Detection — ML pipeline on the PaySim dataset with feature engineering, model comparison (Logistic Regression, Random Forest, HistGradientBoosting) tuned via RandomizedSearchCV (0.9997 test PR-AUC), and a Streamlit app for real-time transaction scoring. NextGen Institute AI internship final project.
